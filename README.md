# PT Barkah Nawabil Santoso

Website company profile statis BNS dengan fokus pengadaan barang.

## Struktur
- index.html: halaman utama
- style.css dan industrial.css: tampilan responsif
- app.js: navigasi dan pratinjau pesan WhatsApp
- assets/: logo serta foto ilustrasi

## Pratinjau lokal
Jalankan `python -m http.server 4173` dari folder ini, lalu buka http://localhost:4173.

## Cloudflare Pages
Hubungkan repositori GitHub ke Cloudflare Pages. Gunakan framework preset None, tanpa build command, dan build output directory `/`.
Alternatif: unggah folder ini menggunakan Direct Upload.

## Catatan
Formulir hanya menyiapkan pesan. Pesan dikirim setelah pengunjung membukanya di WhatsApp dan menekan kirim.
Foto gudang dan produk merupakan ilustrasi stok, bukan dokumentasi fasilitas BNS.
